# Agent Instructions

This project is Tibor Lovas's portfolio site: a Next.js, React, TypeScript, and Tailwind rebuild of a legacy Webflow portfolio.

- Follow the Genome editorial design system and existing component patterns.
- Prefer Tailwind tokens, structured content files, and reusable React sections over one-off styling.
- Preserve legacy Webflow assets unless the user explicitly asks to replace or remove them.
- Keep changes scoped to the requested work.
- Avoid using separation lines if possible.
- Be careful with uncommitted user changes; do not revert or overwrite user work.
